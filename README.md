# Diwali Sales Data Analysis

## Project Overview
This project analyzes Diwali sales data using Python to understand customer purchasing behavior and identify sales trends.

## Objectives
- Analyze sales by gender and age group.
- Identify top-performing product categories and states.
- Understand customer spending patterns.
- Generate business recommendations from the data.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab
- Jupyter Notebook

## Data Cleaning
- Removed empty columns.
- Handled missing values in the `Amount` column.
- Removed duplicate records.
- Prepared the cleaned dataset for analysis.

## Key Findings
- Female customers generated approximately ₹7.43 crore in sales.
- The 26–35 age group had the highest sales, at approximately ₹4.26 crore.
- Food was the highest-selling product category, at approximately ₹3.39 crore.
- Uttar Pradesh recorded the highest sales, at approximately ₹1.93 crore.
- The IT Sector had the highest total sales among occupations, at approximately ₹1.47 crore.
- The dataset contained 3,752 unique customers.
- Average total spending per customer was approximately ₹28,299.
